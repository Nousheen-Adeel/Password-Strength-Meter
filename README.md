# 🔐 Password Strength Meter (Streamlit GUI)

This is a simple yet powerful **Password Strength Checker** built using **Python** and **Streamlit**. It analyzes passwords based on key security factors and provides real-time feedback to the user via a clean and interactive GUI.

---

## 🎯 Features

- ✅ Checks password strength based on:
  - Length
  - Uppercase & lowercase characters
  - Numbers
  - Special characters
- ⚠️ Rejects weak and common passwords (like "password123")
- 🎲 Generates secure password suggestions
- ⚖️ Custom scoring weights for each complexity factor
- 🖥️ Streamlit-powered user-friendly interface

---

## 📦 Requirements

- Python 3.x
- Streamlit (`pip install streamlit`)

---

## 🚀 How to Run

1. Save the code in a file, e.g. `app.py`
2. Open terminal and run:

```bash
streamlit run password_strength.py
